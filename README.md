# My Photo Gallery

- A simple personal website to store and showcase the photos I took.  
- The idea is to create a small online **gallery** instead of just keeping them on my computer.  
- Made for fun, practice, and to have a place to revisit my favorite shots.  
---
## Features
- Displays my photos in a clean gallery layout.  
- Carousel effect for browsing images smoothly.  
- Minimal and lightweight design.  
---
## Built With
- **HTML5**, **CSS3**, **JavaScript**  
- **Normalize.css** for style reset  
- **Google Fonts (Roboto)** for typography  
---
## Demo
- Live site: [My Photo Gallery](https://my-gallery-jade.vercel.app/)  
---
## Structure
- `index.html` – main gallery page  
- `style.css` – styles and layout  
- `script.js` – carousel & interactions  
- `images/` – folder with all my photos
